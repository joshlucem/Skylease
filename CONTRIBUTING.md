# Contributing

Bug reports and pull requests are welcome.

- Open an issue first for anything bigger than a small fix.
- Keep a change to one purpose. Match the surrounding code and comment only what the code cannot say.
- Build with `mvn package` (Java 21) and try the change on a Paper 1.21 server.
- New text goes in every file under `src/main/resources/lang/`. English is the reference.
- Do not remove or alter the built-in credits (see `LICENSE`).

By sending a contribution you agree it is licensed under the same terms as the project (Apache-2.0 with the Credit Preservation Addendum, section 5 of the Apache licence). You keep the copyright in your work and are credited in the history.

Only submit code you wrote or have the right to share. If you used an AI tool, say so in the pull request.
