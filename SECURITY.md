# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and the Skylease and Paper versions. You will get a reply as soon as the maintainer can; this is a volunteer project, so there is no guaranteed response time.

Reports made in good faith, without reading or changing other people's data beyond what proves the issue, will not be treated as hostile.

## Supported versions

Only the latest release receives fixes.
